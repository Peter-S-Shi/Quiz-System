# 安全与隐私

Quiz Studio 是本地优先应用。当前静态版本不会把试卷数据发送到服务器。

## 提交安全

不要提交：

- 用户真实试卷。
- 个人信息。
- 本地机器路径。
- API key、token、密码、cookie、私钥或 `.env` 文件。
- 浏览器导出、备份、日志、缓存、本地数据库或虚拟环境。

## 公开示例

公开示例必须使用合成内容。`examples/` 用于安全示例试卷，`schemas/` 用于公开 schema。

## 本地私有数据

真实本地试卷数据或备份应放在被忽略的目录中，例如 `user-data/` 和 `exports/`。

Learner Response 导出包含原始提交答案和材料快照；Teacher Review 文件可能包含评论或学习诊断。除非文件完全使用合成示例，否则都应按学习者私有数据处理。

Translation Library 备份可能包含用户编写的源材料、可选参考译文和私有 notes。除非所有内容均为合成数据，否则应按本地私有用户数据处理。

外部教师交换通过文件完成。Quiz Studio 不会自动上传导出文件，也不要求 reviewer 账号标识。分享前应检查每个文件；不需要真实身份时，优先使用匿名或合成 reviewer 标签。
