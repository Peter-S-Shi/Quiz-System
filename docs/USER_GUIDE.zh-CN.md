# 使用指南

Quiz Studio 在浏览器中本地运行。它会把试卷、练习进度、答题历史和 finalized Learner Response 保存在浏览器本地存储中。

在 Windows 上，可以在项目文件夹中双击 `start-local.bat`，它会启动本地服务器并打开应用。

## 创建和管理试卷

- 使用本地试卷库新建、复制、重命名、删除、搜索、分类和标记试卷。
- 使用导出功能保存单套试卷。
- 使用备份功能保存完整本地 quiz 与 Translation 数据、答题历史和 finalized Learner Response。

## 练习

- 开始前可以选择题型筛选。
- 输入随机抽题数量即可练习题目子集。
- 刷新恢复可以继续未完成练习。
- 提交后可以在结果页对比自己的答案和正确答案。
- 使用结果页或已关联近期历史中的 **导出作答记录**，下载包含本次题目快照和原始提交答案的可移植 JSON 记录。
- 使用错题重练集中练习最近做错的题目。
- 清空某套试卷历史时，程序会要求确认，并明确删除成绩摘要和对应 Learner Response。

## Translation 练习库

- 切换到 **翻译练习** 标签，打开 Translation Library。
- 先新建一个文件夹，再在其中新建翻译文档，并设置标题、原文语言和目标语言。
- 直接在文档编辑区添加、编辑、重排和删除条目。参考译文只是参考材料，不是唯一正确答案。
- 可以在文档编辑区把文档移动到其他文件夹。
- 使用 **仅原文批量导入** 把粘贴的多行文本转换为条目（不含参考译文），或使用 **双语批量导入** 处理「原文<Tab>参考译文」格式的行。
- 使用 **导入翻译文档 JSON** 引入他人、ChatGPT、Claude、Codex 或其他兼容工具生成的文件。目标文件夹由你选择；文件本身不需要知道你的本地文件夹 ID。
- 每次导入都会先展示预览，包括标题、语言、条目数量、目标文件夹和校验错误，确认后才会写入。如果文件中的 document ID 已经在本地存在，导入会被拒绝，除非你明确选择以新副本方式导入。
- 使用 **导出文档 JSON** 下载翻译文档，格式与导入接受的格式相同，可移植复用。
- 删除文件夹会一并删除其中的翻译文档；删除单个文档是独立的确认操作。两者都只影响浏览器本地数据。

## Translation Practice 练习

- 打开一份至少包含一条条目的翻译文档，选择 **开始练习**。
- 每条条目都会显示原文，请在答案框中独立书写你的译文。参考译文（如果有）默认保持隐藏，直到你主动选择显示——它只是参考材料，不是唯一正确答案，也不会被自动判分。
- 使用 **上一题** / **下一题** 在条目间移动。你的作答和当前位置会随时自动保存。
- 使用 **退出练习** 可以暂时离开而不丢失进度。之后重新打开同一份文档（即使刷新过浏览器）会提供 **继续练习** 或 **放弃练习**；放弃需要确认，且无法撤销。
- 由于同一时间只有一个 Translation Practice session 处于活动状态，如果在另一份文档还有未完成练习时开始新的练习，会先要求确认放弃之前的未完成练习。
- 无论是否已填完全部条目，都可以随时使用 **完成练习**。完成后，你原始提交的译文会作为独立、受保护的 Learner Response 保存——不会计算分数，因为翻译练习是定性评价，而不是判断对错。
- 完成后可以查看已提交的译文、导出作答记录，或对同一份文档重新开始练习。新的一次练习会生成新的证据，不会覆盖之前已完成的记录。
- 书写译文时，可以在自己的作答中选中一个词或短语，标记为 **不认识**、**不确定** 或 **应该会但想不起来**，记录你对这部分译文的信心程度。这些标记只是你个人的元认知信号——它们绝不会被转换成错误答案、分数或词汇记录。
- 随时可以在答案框下方的列表中修改标记的分类或删除它。对完全相同的范围再次标记会替换其分类；与另一个已有标记重叠的范围会被拒绝，直到你先移除或调整那个标记。
- 如果你编辑了某个标记覆盖的文字，一旦锚定文字不再匹配，该标记会被自动移除——会有一条简短提示告诉你发生了这件事。标记会在导航、刷新和继续练习之间保持不变，完成练习时也会原样保留在 finalized evidence 中。

## 批改 / 修订工作区

- 完成一次 Translation Practice 后，可以选择 **打开批改工作区** 来批改这份记录——也可以之后从同一份翻译文档的 **已完成的作答记录** 列表中重新打开。
- 你最初提交的译文始终以只读方式显示，在这个界面无法被编辑；你在练习时做的元认知标记也会显示在旁边，同样是只读的。
- 在原始作答中选中一段文字，可以为它应用 **加粗**、**斜体**、**下划线**、**高亮** 或 **加括号**——这些样式只影响外观展示，可以互相组合、自由重叠。包含旧版“删除线”样式的历史批改仍可正常读取。
- 选中一段文字后选择 **插入**、**替换** 或 **删除/划掉**，可以记录一条内容变更类批改；选择 **添加批注** 可以为该片段附上一条备注。与已有内容变更类批改重叠的新批改会被拒绝——请先移除或调整已有的批改。
- 在应用插入或替换之前，可以从颜色选择器中为插入或替换的文字挑选一种颜色，让你新增的内容与学习者的原始文字在视觉上保持区分。
- 工具栏下方的实时预览会展示批改后的效果：原始文字保持默认颜色，被删除或被替换的部分显示删除线，你插入或替换的文字则以你选择的颜色显示。
- 你还可以为每个条目选填一个评判结果（**正确** / **错误** / **部分正确** / **待复核**）、一条条目级批注，以及一条建议的整体修订译文——它们可以和逐段的批改同时存在。
- 选择 **保存批改** 来保存你的工作。之后重新打开同一份记录（即使刷新过浏览器）会恢复出完全相同的批改内容；再次保存会在原地更新，而不会产生重复记录。
- 批改一份记录绝不会改变原始的 Learner Response——无论批改内容如何编辑或重新保存，学习者提交的原始作答和标记都会保持完成练习时的样子，不会被改动。
- 如果一份记录已经有不止一条批改，打开它的工作区时会先显示一个选择列表（评阅者和 review ID），供你选择要打开哪一条；进入后可以通过切换栏在不同批改之间跳转，或新建一条，都不需要离开工作区。

## 外部教师往返

Quiz Studio 可以让外部的人类教师、AI 助手或其他工具参与到评阅和补救练习中——完全通过手动导出和导入普通 JSON 文件完成。应用本身不会调用任何外部 AI 服务，也不需要 API key。

- 完成一次 Translation Practice 后（或从同一份文档的 **已完成的作答记录** 列表中），选择 **导出外部评阅请求** 下载一份自包含的评阅请求文件。它包含外部评阅者所需的全部信息——原文、你的译文、你的标记和语言信息，不需要访问这个浏览器的本地存储。
- 把这份文件交给负责评阅的人（教师、AI 助手或其他工具）。请他们返回一个符合 Quiz Studio Teacher Review 格式的单一 JSON 文件；评阅请求文件本身就说明了这项要求。
- 回到 Quiz Studio，在同一条作答记录上使用 **导入 Teacher Review**，选择返回的 JSON 文件。预览会显示目标作答记录、评阅者、review ID，以及这是一条新批改、内容相同的重复导入，还是对已有批改的更新，并显示条目数和批改数。查看无误后点击 **确认导入** 保存；或点击 **取消** 放弃，不会对已保存的任何内容产生影响。
- 一份作答记录随时间可以收到不止一条批改；导入一条新的绝不会删除或隐藏之前的。
- 保存批改后，可以在批改工作区中打开它，选择 **导出批改 JSON** 保存一份可移植的副本，或选择 **导出补救练习请求** 把这条批改和原始作答记录打包成一份文件，交给外部人员撰写有针对性的后续练习材料。
- 把补救练习请求文件交给负责生成新材料的人。请他们为 **导入补救练习材料**（在 Translation Library 的导入区域，与其他导入方式并列）返回一份 Translation Document JSON 文件。其 `provenance` 必须包含 `purpose: "remediation"`、请求中的 `sourceResponseId` 和 `sourceReviewId`、采用 ISO 8601 时间戳的 `createdAt`，以及使用受支持 actor 结构的 `author`，例如 `{ "type": "external-ai", "displayLabel": "Synthetic Reviewer" }`。`sourceMaterialId` 可选；提供时必须与来源 response 的材料 ID 一致。
- 导入补救练习材料时，Quiz Studio 会检查它是否真的能追溯回你导出时对应的作答记录和批改——如果一份文件自称是补救材料，却指向不存在或对不上的证据，会被拒绝导入。像导入其他翻译文档一样选择目标文件夹即可。
- 练习导入的补救材料和练习其他任何材料完全一样；产生的证据会保留它源自哪份原始作答记录和批改的记录，即使之后删除了这份补救文档也是如此。

## Translation 历史、重新练习与溯源

- 在 Translation Library 中选择 **翻译历史**，即可浏览全部已完成的翻译作答记录，无论其原始文档是否还存在。每条记录会显示材料标题、语言、完成时间、条目数、批改数，以及需要加强、已生成补救材料、已重新练习等徽章。
- 可以按来源（正常练习、重新练习或补救练习）、按批改状态（未批改、已批改或需要加强）筛选，并按最新或最早排序。
- 打开一条记录可以查看完整证据：每个条目的原文和你的原始作答、你做过的元认知标记、每一条关联的 Teacher Review（可以打开某一条，也可以删除不再需要的一条），以及在适用时的 **溯源链**（这条记录来自哪里）和 **由此派生出的记录**（哪些重新练习或补救练习源自它）。如果某条关联记录已被删除，会明确标注为不可用，而不是被悄悄隐藏。
- 在历史详情中，可以使用 **整份重新练习** 针对同一份材料重新开始一次全新的练习，使用 **选择条目重新练习** 精确挑选要重做的条目，或使用 **针对需要加强的条目重新练习** 自动只重新练习带有标记或批改提示的条目。每一次重新练习都会产生新的、独立的证据——绝不会覆盖或重新打开原始记录。
- 历史详情中同样提供 **导出作答记录** 和 **导出外部评阅请求**，以及针对不再需要的记录的 **删除这条历史记录**。如果这条记录有批改，或有由它派生出的重新练习/补救记录，确认提示会先说明清楚会发生什么，再让你决定是否继续。
- 删除一份已经有 finalized 作答记录的翻译文档，不会让这些证据消失——它们依然可以在翻译历史中完整浏览和重新练习；删除文档前的确认提示会告知有多少条作答记录与之关联。
- 如果某条作答记录或某份批改在你的 Translation Library 中还有**实时存在**的补救材料是基于它生成的，删除这条作答记录或批改会被阻止，并提示你先删除对应的补救材料。这只针对仍然存在于你库中的补救材料；仅仅是过去做过一次重新练习或补救练习，绝不会阻止你删除对应的作答记录或批改。

## 数据安全

导出的 response 和备份文件可能包含用户编写的 quiz 或 Translation 材料、参考译文、私有 notes 与学习者答案。文件由你自行管理，程序不会自动上传。真实数据应放在仓库外，或放在被忽略的 `user-data/`、`exports/` 等目录中；分享给外部教师前应检查文件内容。

缺少 Learner Response 的旧备份仍可读取，并且不会静默删除现有作答记录。
