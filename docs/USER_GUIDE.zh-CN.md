# 使用指南

Quiz Studio 在浏览器中本地运行。它会把试卷、练习进度和答题历史保存在浏览器本地存储中。

## 创建和管理试卷

- 使用本地试卷库新建、复制、重命名、删除、搜索、分类和标记试卷。
- 使用导出功能保存单套试卷。
- 使用备份功能保存完整本地试卷库和答题历史。

## 练习

- 开始前可以选择题型筛选。
- 输入随机抽题数量即可练习题目子集。
- 刷新恢复可以继续未完成练习。
- 提交后可以在结果页对比自己的答案和正确答案。
- 使用错题重练集中练习最近做错的题目。

## 数据安全

导出的 JSON 文件由你自行管理。真实试卷数据应放在仓库外，或放在被忽略的 `user-data/`、`exports/` 等目录中。
