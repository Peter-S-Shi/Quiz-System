# 使用指南

Quiz Studio 在浏览器中本地运行。它会把试卷、练习进度、答题历史和 finalized Learner Response 保存在浏览器本地存储中。

在 Windows 上，可以在项目文件夹中双击 `start-local.bat`，它会启动本地服务器并打开应用。

## 创建和管理试卷

- 使用本地试卷库新建、复制、重命名、删除、搜索、分类和标记试卷。
- 使用导出功能保存单套试卷。
- 使用备份功能保存完整本地 quiz 与 Translation 数据、答题历史和 finalized Learner Response。

## 练习

- 开始前可以选择题型筛选。
- 输入随机抽题数量即可练习题目子集。
- 刷新恢复可以继续未完成练习。
- 提交后可以在结果页对比自己的答案和正确答案。
- 使用结果页或已关联近期历史中的 **导出作答记录**，下载包含本次题目快照和原始提交答案的可移植 JSON 记录。
- 使用错题重练集中练习最近做错的题目。
- 清空某套试卷历史时，程序会要求确认，并明确删除成绩摘要和对应 Learner Response。

## Translation 练习库

- 切换到 **翻译练习** 标签，打开 Translation Library。
- 先新建一个文件夹，再在其中新建翻译文档，并设置标题、原文语言和目标语言。
- 直接在文档编辑区添加、编辑、重排和删除条目。参考译文只是参考材料，不是唯一正确答案。
- 可以在文档编辑区把文档移动到其他文件夹。
- 使用 **仅原文批量导入** 把粘贴的多行文本转换为条目（不含参考译文），或使用 **双语批量导入** 处理「原文<Tab>参考译文」格式的行。
- 使用 **导入翻译文档 JSON** 引入他人、ChatGPT、Claude、Codex 或其他兼容工具生成的文件。目标文件夹由你选择；文件本身不需要知道你的本地文件夹 ID。
- 每次导入都会先展示预览，包括标题、语言、条目数量、目标文件夹和校验错误，确认后才会写入。如果文件中的 document ID 已经在本地存在，导入会被拒绝，除非你明确选择以新副本方式导入。
- 使用 **导出文档 JSON** 下载翻译文档，格式与导入接受的格式相同，可移植复用。
- 删除文件夹会一并删除其中的翻译文档；删除单个文档是独立的确认操作。两者都只影响浏览器本地数据。

## 数据安全

导出的 response 和备份文件可能包含用户编写的 quiz 或 Translation 材料、参考译文、私有 notes 与学习者答案。文件由你自行管理，程序不会自动上传。真实数据应放在仓库外，或放在被忽略的 `user-data/`、`exports/` 等目录中；分享给外部教师前应检查文件内容。

缺少 Learner Response 的旧备份仍可读取，并且不会静默删除现有作答记录。
