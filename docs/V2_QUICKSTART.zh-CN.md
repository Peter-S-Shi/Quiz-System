# Quiz Studio V2 —— 桌面版快速上手（2.0.0）

Quiz Studio V2 是一款 Windows 桌面应用，用于本地优先的练习：客观题试卷、带 Teacher Review 的翻译练习、跟打练习，并带有证据历史和学习日历。它完全在你的电脑上运行，不需要账号，没有云端，也不联网。

> **状态：已发布，`2.0.0`。** **仅在 Windows 上验证**（Windows 11、WebView2）。macOS 延后，**未验证**。

## 安装与启动

1. 运行安装程序（`quiz-studio_2.0.0_x64-setup.exe`，取自 GitHub Release `v2.0.0`；请对照随它发布的校验文件核对 SHA-256）。它按**当前用户**安装，不需要管理员权限。
2. 应用依赖微软 **WebView2** 运行时，当前的 Windows 11 已自带。如果缺失，安装程序会下载一次；这是安装程序唯一一次用到网络。
3. 从开始菜单启动 **Quiz Studio**。**设置 → System** 会显示版本（`Quiz Studio 2.0.0`）。

## 数据存放在哪里

你创建的一切都存放在你电脑上、你个人的 Windows 应用数据区里的一个由应用管理的数据文件夹中。你不需要去找它：用**交换与备份**保存副本即可，应用不会向任何地方发送任何内容。请不要手动修改该文件夹。

## 主要视图

- **今日** —— 现在该练什么：附带推荐理由的建议、到期项目，以及可以继续的未完成练习。从这里开始会记录你为什么开始。
- **日历** —— 按月显示学习计划。可以移动、跳过或取消某次安排；建议的日期会等你决定。
- **资料库** —— 你的学习材料。**新建**可创建客观题试卷、翻译文档或跟打文本。每一行带有一个克制的事实状态：*未开始*、*进行中*、*已练习*（只是事实，不是掌握度）。选择条目即可练习；客观题试卷可以选择打乱题目顺序。
- **Focused Practice（专注练习）** —— 三类练习共用的无干扰界面。客观题支持即时反馈或*交卷后再看*；翻译可标记不确定的句子；跟打能跟随长文本并支持输入法。练习中途退出会询问保存并离开还是放弃。
- **证据历史** —— 每次完成的练习都以记录的事实呈现（客观题得分、跟打用时），并可重做做错的题。
- **批改** —— 对翻译作答做 Teacher Review，作为独立记录保存。
- **设置** —— 语言（English / 简体中文）、外观、音效（默认关闭）、媒体文件，以及 **System**（版本、存储健康状态、V1 导入）。

## 备份与恢复

**交换与备份 → 备份 → 立即备份…** 会生成一个 `.qsarchive` 文件，包含你的材料、证据、批改和媒体。恢复时选择**选择备份…**，查看预览后确认。替换前会自动保留一份当前数据的快照；取消不会改动任何东西。

## 导入 Quiz Studio V1 的数据

**设置 → System → Import from Quiz Studio V1 → Choose V1 backup…**。先给出预览（数量、媒体、说明、V1 从未包含的内容），确认前不会有任何改动。重复导入同一份备份会被识别并且什么都不做。导入可以撤销（如果之后的数据依赖它则会被拒绝）。不是 V1 备份的文件会被拒绝并给出说明，且不改动任何数据。

## 卸载

在 Windows 设置中卸载。卸载程序会询问是否**删除应用数据**：不勾选则保留数据，便于以后重新安装；勾选则全部删除。

## 2.0.0 的已知限制

- **历史很大时加载较慢。** 资料库状态和今日会读取整段历史；完成几千次练习之后，这些视图出现得会明显更慢（实测数字见 `docs/V2_RELEASE_CANDIDATE.md`：在一台当前的笔记本上，完成 5 000 次练习时资料库约 1 秒、今日约 1.6 秒）。不会丢失数据，也不会出错。
- **导出会原地覆盖你选择的文件。** 交换导出直接写入你在保存对话框里选定的文件，不会触碰你的 Quiz Studio 数据；如果写入失败，受影响的只有那个导出文件。
- **仅限 Windows。** 不支持、也未验证 macOS 和 Linux。
- 应用没有代码签名，也不会自动更新；首次运行时 Windows 可能提示“无法识别的应用”。
