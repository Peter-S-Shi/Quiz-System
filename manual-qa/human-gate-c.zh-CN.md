# Human Gate C 人工验收指南 — 客观题多媒体支持（图片与音频）

**范围**：Pre-Freeze V1 Scope Closure · Batch C  
**状态**：待评估 PENDING EVALUATION  
**评估人**：人工评阅人 / 产品负责人  

---

## 概述

本指南为 Pre-Freeze V1 范围收尾 Batch C 中引入的客观题多媒体支持功能提供分步验证旅程：
1. **5 种客观题型全覆盖多媒体**：单选、多选、填空、判断、匹配全部 5 种客观题型均支持可选附加图片、音频，或同时附加图片与音频。
2. **纯本地离线媒体存储架构**：使用基于 IndexedDB 的二进制本地媒体资产库（`quiz-studio-media-db` / `media_assets` 对象仓库），以原生 Blob 形式持久化，题目 JSON 中仅持有稳定的唯一 ID 与元数据引用。
3. **图片编排、预览与无障碍 Alt 说明**：支持本地图片上传（PNG、JPEG、WebP、GIF、SVG）、实时缩略图预览、文件大小展示、替换、移除及无障碍 Alt 文本配置。
4. **交互式图片模态查看器**：响应式全屏/模态查看器（`#imageViewerDialog`），支持放大（`+`）、缩小（`-`）、重置（`1:1`）、关闭（`✕`）以及键盘快捷键（`+`、`-`、`0`、`Esc`）。
5. **音频编排与作答播放器**：支持本地音频上传（MP3、WAV、OGG、WebM、AAC、M4A、FLAC）、编辑器内试听、以及作答界面中的题目内嵌播放控件（支持播放/暂停、进度拖拽与无限次重播）。
6. **单卷便携包与全库备份恢复（带引用完整性校验）**：导出包含 base64 媒体负载的自包含信封包（`quiz-studio.quiz-paper` v2），导入时严格校验引用完整性（若缺失媒体则安全拒绝），全量备份支持 `mediaAssets`，并完全向下兼容纯文本遗留 JSON 试卷。
7. **作答证据不可变性与引用感知保守清理**：进行中会话快照与已归档 Learner Response 快照对媒体引用的独立持久留存，以及结算复盘列表中的图片缩略图（点击放大）与内嵌音频播放。

## 验证旅程 1：全部 5 种客观题型的多媒体编排

### 验证目标
验证全部 5 种客观题型均可正常添加图片和音频附件（单独或同时存在），具备格式校验、实时缩略图/播放器预览、替换、移除与 Alt 说明编辑。

### 步骤
1. 启动 Quiz Studio（执行 `start-local.bat` 或 `python scripts/dev-server.py`）。
2. 进入**编辑**（Edit）模式，选择或创建一份试卷，进入 Level 3（题目层）。
3. 分别测试 5 种题型：
   - **单选题**：点击**题目图片**下的 `+ 添加图片`，上传 `manual-qa/media-sample/assets/geometry-angles.svg`。确认出现缩略图、文件名与大小。填写 Alt 文本：`几何角度图`。
   - **多选题**：点击**题目音频**下的 `+ 添加音频`，上传 `manual-qa/media-sample/assets/mystery-pitch-sequence.wav`。确认音频播放器控件出现并可在编辑器内正常试听。
   - **填空题**：在同一题中**同时附加** `manual-qa/media-sample/assets/data-structure.svg`（图片）与 `manual-qa/media-sample/assets/chime-440hz.wav`（音频）。确认两块媒体预览区域并存且无界面冲突。
   - **判断题**：附加 `manual-qa/media-sample/assets/data-structure.svg`。点击 `替换图片` 按钮选择 `geometry-angles.svg`，确认图片即时更新。
   - **匹配题**：附加 `manual-qa/media-sample/assets/beep-880hz.wav`。点击 `移除音频` 按钮，确认音频被清理且恢复空状态。
4. **反向校验**：
   - 尝试上传不支持的格式（如 `.txt`、`.pdf` 或 `.mp4`）到图片或音频上传框。
   - 确认弹出错误提示 Toast 且未破坏编辑器状态。

## 验证旅程 2：本地离线 IndexedDB 原生 Blob 存储

### 验证目标
验证二进制多媒体资产以原生 Blob 格式保存在本地 IndexedDB（`quiz-studio-media-db`）中，在页面刷新和完全离线状态下不丢失。

### 步骤
1. 在题目编辑器中为题目添加一张图片和一个音频。
2. 打开浏览器开发者工具（`F12`）-> **Application** -> **IndexedDB** -> `quiz-studio-media-db` -> `media_assets`。
3. 检查是否存在以 `img-...` 和 `aud-...` 为 Key 的记录，且字段中包含 MIME 类型、文件名、字节大小以及原生的 `Blob` 二进制对象。
4. 强制刷新页面（`Ctrl+F5`）。
5. 回到编辑模式：
   - 确认图片缩略图正常从 IndexedDB 加载并显示。
   - 确认音频播放器控件正常加载并可播放。
6. 断开网络或在 DevTools Network 选项卡勾选 "Offline"：
   - 确认所有媒体资产仍能正常加载与播放，零网络请求。

## 验证旅程 3：作答界面渲染与听力必答题体验

### 验证目标
验证作答界面在全部 5 种客观题型中均能自适应呈现图片与音频播放器，支持播放、暂停、拖拽进度条与无限次重播，且包含必须通过看图与听音才能作答的题目。

### 步骤
1. 切换到**练习**（Practice）模式，选择导入 `manual-qa/media-sample/quiz-studio-media-sample-paper.json` 样卷开始做题。
2. **Q1（依赖图片的单选题）**：
   - 观察几何角度图：标出的锐角 θ 测量值为 37°。
   - 选择 `θ = 37°`。
3. **Q2（必须听音作答的多选题）**：
   - 点击题目内的音频播放器播放。
   - 仔细聆听 3 段脉冲音频（低音 -> 高音 -> 低音）。
   - 选择对应音调轮廓的正确选项（选项 A 与 B：低 → 高 → 低，且第 1 声与第 3 声脉冲具有相同的较低基频）。注意：不听音频无法推断出正确答案。
4. **Q3（图音双附填空题）**：
   - 观察链表图与提示音播放器，输入中间节点的数值 `45`。
5. **Q4 与 Q5（判断题与匹配题）**：
   - 完成剩余多媒体题目的作答与配对。
6. 完成并提交试卷，观察得分与结算反馈。

## 验证旅程 4：交互式图片模态查看器与键盘缩放

### 验证目标
验证模态图片查看器（`#imageViewerDialog`）、点击放大交互、缩放比例调节（25% 到 400%）、重置与键盘快捷键。

### 步骤
1. 在练习模式下，停留在附带图片的题目（如 Q1）。
2. 点击图片（或通过 `Tab` 键聚焦后按 `Enter` / 空格键）：
   - 确认弹出高斯模糊背景的模态图片查看器。
   - 确认初始缩放比例显示为 `100%`。
3. 测试工具栏按钮：
   - 点击 `+`（放大）：确认图片每次放大 25%，最高可达 400%。
   - 点击 `-`（缩小）：确认图片每次缩小 25%，最低可缩至 25%。
   - 点击 `1:1`（重置）：确认缩放比例恢复 100%。
   - 点击 `✕`（关闭）：确认模态窗关闭并还原焦点。
4. 重新打开图片查看器，测试**键盘快捷键**：
   - 按 `+` 或 `=`：图片放大。
   - 按 `-` 或 `_`：图片缩小。
   - 按 `0`：缩放重置为 100%。
   - 按 `Escape`：模态窗关闭。

## 验证旅程 5：单卷便携导出导入、引用完整性校验与遗留兼容性

### 验证目标
验证单卷导出生成包含 base64 媒体负载的自包含便携包（`quiz-studio.quiz-paper` v2），导入时具备严格的引用完整性校验，并无缝兼容遗留纯文本 JSON 试卷。

### 步骤
1. 在编辑侧边栏 Level 3，点击当前样卷的**导出**（Export）。
2. 用文本编辑器打开下载的 `.json` 文件：
   - 检查文件结构：`schemaVersion: 2`, `documentType: "quiz-studio.quiz-paper"`, `paper: { ... }`, `assets: [ { id, mimeType, name, size, data } ]`。
   - 确认二进制媒体数据在 JSON 传输边界被编码为 base64 字符串。
3. 清空浏览器缓存或打开无痕模式。
4. 在编辑模式点击**导入**（Import），选择刚刚导出的 JSON。
5. 验证：
   - 试卷成功导入试卷库。
   - base64 资产被自动还原为 Blob 并写入 IndexedDB。
   - 题目编辑器与练习模式下所有图片与音频均能立即正常呈现与播放。
6. **引用完整性反向校验**：
   - 手动篡改一份导出的 JSON，删除 `assets` 中的某个引用资产或将其数据置空。
   - 尝试导入该损坏文件：确认导入被安全拦截并弹出错误 Toast，未污染试卷库。
7. **遗留纯文本兼容性**：
   - 导入一份既有的旧版本纯文本 JSON 试卷（如 `manual-qa/samples/quiz-normal-sample.json`）。
   - 确认旧试卷正常导入，媒体字段平滑规整为 undefined。

## 验证旅程 6：包含媒体资产的全量备份与恢复

### 验证目标
验证全量备份打包所有试卷、进行中会话与历史快照所引用的媒体资产，恢复时能完整重建 IndexedDB 与试卷库。

### 步骤
1. 在编辑侧边栏 Level 1，点击**备份**（Backup）。
2. 查看导出的 `quiz-studio-backup-*.json`：
   - 检查 `documentType: "quiz-studio.library-backup"`。
   - 确认顶层 `mediaAssets` 数组包含库内所有被引用的图片与音频。
3. 在新无痕窗口中打开应用，点击**导入备份**（Import backup）并选取该文件。
4. 验证：
   - 试卷库与分类完全恢复。
   - IndexedDB 中的媒体资产全部恢复为原生 Blob。
   - 打开包含多媒体的试卷，图片与音频均能正常预览与播放。

## 验证旅程 7：作答证据不可变性与引用感知保守清理

### 验证目标
验证进行中作答会话与已归档 Learner Response 快照独立保存媒体引用，结算复盘列表提供缩略图放大，且后续编辑或删除活动试卷绝不损坏历史作答证据。

### 步骤
1. 练习多媒体样卷并完成交卷。
2. 在**结算与复盘列表**中：
   - 附带图片的题目呈现可点击的缩略图（`.review-thumb-img`）。
   - 点击缩略图弹出模态图片查看器。
   - 附带音频的题目呈现内嵌播放器（`.review-audio-inline`）并可播放。
3. 回到编辑模式修改原试卷：
   - 删除第 1 题的图片并修改题干。
4. 打开作答历史并导出 Learner Response：
   - 检查导出的 JSON 中快照题目（snapshot items）依然保留原有的 `image.id` 与原题干，未被后续修改覆盖。
   - IndexedDB 中的原图片资产因为仍被历史记录引用而被安全保留，不会被清理。
