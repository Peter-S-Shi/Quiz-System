# Human Gate C 验证指南 — 客观题多媒体支持（图片与音频）

**范围**：Pre-Freeze V1 Scope Closure · Batch C（客观题多媒体）  
**状态**：待评估（PENDING EVALUATION）  
**评估人**：人工验收人 / 产品负责人（Product Owner）  

---

## 概述

本指南为 Pre-Freeze V1 Scope Closure Batch C（客观题多媒体支持）所引入的核心能力提供逐项验证路径：
1. **5 种客观题型全覆盖**：单选题、多选题、填空题、判断题、匹配题均可配置图片与音频。
2. **纯本地离线媒体存储架构**：采用 IndexedDB 承载的本地媒体资产库（`quiz-studio-media-db` / `media_assets` 对象仓库），题目 JSON 中仅持有稳定的唯一 ID 与元数据引用。
3. **图片编排、预览与无障碍 Alt 文本**：支持本地图片上传（PNG、JPEG、WebP、GIF、SVG）、实时缩略图预览、替换、移除及无障碍说明（Alt）编辑。
4. **交互式图片放大查看器**：响应式模态查看器，支持放大（`+`）、缩小（`-`）、重置（`1:1`）、关闭（`✕`）及键盘快捷键（`+`、`-`、`0`、`Esc`）。
5. **音频编排与作答播放器**：支持本地音频上传（MP3、WAV、OGG、WebM、AAC、M4A、FLAC）、编辑器内试听、以及作答界面中的播放/暂停、进度拖拽与无限次重播。
6. **单卷便携性与全库备份恢复**：导出包含 base64 媒体负载的自包含信封包（`quiz-studio.quiz-paper`），导入时自动同步 IndexedDB 媒体库，并无缝向下兼容纯文本遗留 JSON。
7. **作答证据不可变性与历史快照安全**：进行中会话快照、已归档 Learner Response 快照对媒体引用的持久留存，以及结算复盘列表中的图片缩略图（点击放大）与内嵌音频播放。

## 验证旅程 1：客观题多媒体编排（5 大题型全覆盖）

### 目标
验证全部 5 种客观题型均可独立或同时附加图片与音频，并支持格式校验、实时缩略图/播放器预览、替换、移除及 Alt 文本配置。

### 步骤
1. 启动 Quiz Studio（执行 `start-local.bat` 或 `python scripts/dev-server.py`）。
2. 在顶部导航栏切换至**编辑**模式，选择或新建试卷，进入 Level 3（题目列表与编排）。
3. 分别测试各题型：
   - **单选题**：在“题目配图”区域点击 `+ 添加图片`，上传 `manual-qa/media-sample/assets/geometry-angles.svg`。确认显示缩略图、文件名与文件大小。填写 Alt 文本：`几何角度参考图`。
   - **多选题**：在“题目音频”区域点击 `+ 添加音频`，上传 `manual-qa/media-sample/assets/chime-440hz.wav`。确认编辑器内出现音频播放控件并可正常试听。
   - **填空题**：在同一题中**同时**上传 `manual-qa/media-sample/assets/data-structure.svg`（图片）与 `manual-qa/media-sample/assets/beep-880hz.wav`（音频）。确认图音两个区域整洁并列，无布局错位。
   - **判断题**：上传 `manual-qa/media-sample/assets/data-structure.svg` 后，点击 `替换图片` 选择 `geometry-angles.svg`，确认预览图立即无缝更新。
   - **匹配题**：上传 `manual-qa/media-sample/assets/chime-440hz.wav` 后，点击 `移除音频`，确认音频被干净移除并恢复 `+ 添加音频` 初始状态。
4. **反向校验**：
   - 尝试上传不支持的文件格式（如 `.txt`、`.pdf`、`.mp4` 或可执行文件）。
   - 确认弹出友好提示，非法文件被安全拦截且编辑器状态完好无损。

## 验证旅程 2：纯本地离线媒体存储与 IndexedDB 持久化

### 目标
验证二进制媒体文件安全存储于浏览器本地 IndexedDB（`quiz-studio-media-db`），在页面刷新及离线状态下完好保存且无需外部网络。

### 步骤
1. 在题目编辑器中为题目添加图片与音频。
2. 打开浏览器开发者工具（`F12`）-> **应用（Application）** -> **IndexedDB** -> `quiz-studio-media-db` -> `media_assets`。
3. 确认存在对应 ID（`img-...`、`aud-...`）的媒体记录，包含 MIME 类型、文件名、字节大小和二进制数据。
4. 强制刷新页面（`Ctrl+F5` 或 `Cmd+Shift+R`）。
5. 回到该题目的编辑界面：
   - 确认图片缩略图预览即时从 IndexedDB 读取呈现。
   - 确认音频播放器即时就绪并可播放。
6. 断开网络或在开发者工具 Network 面板中勾选“Offline”：
   - 确认所有媒体资源在零网络请求下正常加载与播放。

## 验证旅程 3：练习模式内嵌呈现与音频播放

### 目标
验证练习作答界面在全部 5 种客观题型中均能自适应呈现高清配图与原生音频控件，支持播放、暂停、进度条拖拽与无限次重播。

### 步骤
1. 切换至**练习**模式，使用刚刚创建的试卷或导入 `manual-qa/media-sample/quiz-studio-media-sample-paper.json` 开始答题。
2. 观察题目的多媒体排版：
   - 包含图片的题目：确认图片居中自适应缩放，边缘清晰，右下角带有 `🔍 点击放大` 浮层提示。
   - 包含音频的题目：确认音频播放条清晰可见，包含播放/暂停、时间轴拖拽与计时显示。
   - 图音双附题目：确认图片与音频纵向优雅堆叠，不遮挡题目题干与选项。
3. 测试音频播放：
   - 点击播放：确认声音清脆播放。
   - 拖拽进度条到中段：确认精准定位播放。
   - 反复多次播放：确认 V1 支持无限次重播。
4. 完成作答并提交试卷。

## 验证旅程 4：交互式图片模态查看器与缩放控制

### 目标
验证模态图片查看器（`#imageViewerDialog`）的点击唤起、缩放级别控制（25% ~ 400%）、重置及键盘操作。

### 步骤
1. 在练习模式下进入附带图片的题目。
2. 点击图片区域（或使用 `Tab` 键聚焦后按 `Enter` / `Space`）：
   - 确认弹出**图片查看器模态对话框**，背景带有半透明毛玻璃遮罩。
   - 确认顶部工具栏初始缩放级别显示 `100%`。
3. 测试工具栏按钮：
   - 点击 `+`（放大）：确认图片逐级放大（每次 +25%，如 125%、150%），最大支持 400%。
   - 点击 `-`（缩小）：确认图片逐级缩小，最小支持 25%。
   - 点击 `1:1`（重置）：确认缩放比例瞬间恢复为 100%。
   - 点击 `✕`（关闭）：确认查看器平滑关闭并将焦点退回作答区。
4. 再次打开查看器，测试**键盘快捷键**：
   - 按 `+` 或 `=`：确认图片放大。
   - 按 `-` 或 `_`：确认图片缩小。
   - 按 `0`：确认重置为 100%。
   - 按 `Escape`：确认关闭模态框。

## 验证旅程 5：单卷便携性与向下兼容性

### 目标
验证单卷导出可生成自包含 base64 媒体负载的便携包（`quiz-studio.quiz-paper`），在新实例中完整还原试卷与媒体资产，且向下兼容历史纯文本试卷。

### 步骤
1. 在编辑侧边栏 Level 3 中点击**导出**。
2. 在文本编辑器中打开下载的 `.json` 文件：
   - 确认包结构包含 `schemaVersion: 2`、`documentType: "quiz-studio.quiz-paper"`、`paper: { ... }` 与 `assets: [ ... ]`。
   - 确认媒体二进制数据作为 base64 字符串打包在 `assets` 中。
3. 清除应用数据或开启隐身浏览器窗口。
4. 在编辑模式点击**导入**，选择刚才导出的试卷 JSON。
5. 验证：
   - 试卷成功添加至试卷库。
   - 媒体资产自动解析并写入 IndexedDB。
   - 题目编辑器与练习模式中配图与音频均可立即正常显示与播放。
6. **遗留纯文本试卷兼容测试**：
   - 导入历史旧格式试卷（如 `manual-qa/samples/quiz-normal-sample.json`）。
   - 确认无媒体字段的旧试卷平滑导入且无任何报错。

## 验证旅程 6：全库备份与恢复（含二进制媒体资产）

### 目标
验证全库备份完整打包活体试卷、会话与学习记录中引用的所有媒体资产，并在恢复时同步重建 IndexedDB 与试卷库。

### 步骤
1. 在编辑侧边栏 Level 1 点击**备份**。
2. 检查下载的 `quiz-studio-backup-*.json`：
   - 确认 `documentType: "quiz-studio.library-backup"`。
   - 确认顶层 `mediaAssets` 数组包含库内引用的全部图片与音频资产。
3. 打开干净浏览器配置或清空本地数据（`localStorage.clear()` 并删除 IndexedDB）。
4. 在编辑侧边栏 Level 1 点击**导入备份**并选择该备份文件。
5. 验证：
   - 试卷库与分类全量恢复。
   - IndexedDB `quiz-studio-media-db` 成功重建并写入全部媒体。
   - 恢复后的多媒体题目缩略图与音频播放器立即可用。

## 验证旅程 7：作答证据不可变性与复盘列表

### 目标
验证进行中练习会话与已完成 Learner Response 对媒体快照的不可变持有，结算复盘界面的缩略图与音频回放，以及修改活体试卷绝不污染历史证据。

### 步骤
1. 对一份多媒体试卷完成练习并交卷。
2. 在**成绩与复盘**界面：
   - 确认带图片的题目下方渲染了图片缩略图（`.review-thumb-img`）。
   - 点击缩略图能够唤起图片查看器放大审视。
   - 确认带音频的题目下方渲染了内嵌音频播放器（`.review-audio-inline`）且能正常回放。
3. 返回编辑模式修改原始试卷：
   - 移除第 1 题的配图并修改其题干文本。
4. 查看作答历史：
   - 从历史记录中导出 Learner Response JSON。
   - 确认 Learner Response 快照中的第 1 题依然完好保留着原始 `image.id` 与原始题干，未被后续修改所污染。
