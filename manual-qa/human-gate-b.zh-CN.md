# Human Gate B 人工验证指南 — 试卷库组织与渐进式层级导航

**所属阶段**: 冻结前 V1 范围收敛 · Batch B（试卷库集合式分类组织）  
**评审状态**: 通过 (PASS · 产品负责人已验收)  
**评估人**: 人工评审员 / 产品负责人 (Product Owner)  

---

## 概述

本指南提供对“冻结前 V1 范围收敛 Batch B”新增的试卷库分类管理与 UI 渐进式导航特性的逐项验收旅程：
1. **侧边栏渐进式单层导航模型 (Level 1 → Level 2 → Level 3)**:
   - **Level 1（分类层）**: 显示所有试卷、用户创建分类、未分类、分类管理操作及备份工具。
   - **Level 2（试卷层）**: 显示返回分类层面包屑、当前分类信息与计数、作用域限定搜索及试卷操作。
   - **Level 3（题目层）**: 显示返回试卷层面包屑、当前试卷信息与分类徽标、试卷属性及题目列表与出题操作。
2. **分类管理、无障碍支持与系统保护**: 全键盘无障碍支持（Tab / Enter / Space）、系统保留字保护（`__ALL__`、`__UNCATEGORIZED__`、`__NEW_CATEGORY__`）、空分类持久化。
3. **试卷归类、分类搜索作用域与行内新建**: 试卷归类与重新归属、分类下新建试卷继承归属、搜索框限定当前分类。
4. **分类重命名与防碰撞安全**: 分类注册表更新并自动无损传播到该分类下的所有试卷，保留字校验，重命名撞名时安全拦截拒绝（防止静默合并分类）。
5. **精细化分类删除弹窗与安全契约**:
   - 包含标准弹窗标题与右上角关闭按钮的标准 Header。
   - 明确区分安全选项卡（“仅删除分类”）与破坏性选项卡（“删除分类及所有试卷”，注明永久删除数量）。
   - 次要样式的取消操作，符合 Layered Paper Study Desk 设计规范，以及破坏性二次确认。
6. **备份与恢复兼容性与国际化**: 完整备份 JSON 对分类注册表的保留与中英双语本地化覆盖。

## 验证旅程 1: 侧边栏渐进式单层导航模型

### 目标
验证编辑侧边栏采用清晰的单层渐进式导航模型（分类 → 试卷 → 题目），消除视觉杂乱与认知负担，并在各层级之间提供顺畅明确的面包屑返回导航。

### 步骤
1. 启动 Quiz Studio（执行 `start-local.bat` 或 `python scripts/dev-server.py`）。
2. 在顶部导航栏切换至 **编辑** 模式。
3. **检查 Level 1（分类层）**:
   - 如果侧边栏当前正处于试卷编辑中，点击顶部的 `← 返回试卷列表`，然后再点击 `← 返回分类列表`。
   - 确认 Level 1 界面**仅包含**：
     - 标题 `本地试卷库` 与试卷总数。
     - 分类列表：`所有试卷`、各用户分类（如有）、`未分类`。
     - `+ 新建分类` 按钮。
     - 全量备份操作（`备份` / `导入备份`）。
   - 确认试卷属性、题目列表与出题按钮在此层级下**完全隐藏**。
4. **进入 Level 2（试卷层）**:
   - 点击 `所有试卷`（或任意分类项）。
   - 确认侧边栏平滑切换至 Level 2：
     - 顶部显示清晰的面包屑返回按钮：`← 返回分类列表`。
     - 标题区展示当前分类名称与试卷计数：`📋 所有试卷 (N)`。
     - 搜索框占位符提示限定在当前分类。
     - 试卷操作按钮组：`新建`、`复制`、`重命名`、`删除`。
     - 筛选后的试卷列表。
5. **进入 Level 3（题目层）**:
   - 点击列表中任意一份试卷。
   - 确认侧边栏平滑切换至 Level 3：
     - 顶部显示清晰的面包屑返回按钮：`← 返回试卷列表`。
     - 试卷摘要卡片展示试卷标题与分类徽标。
     - 试卷属性字段：试卷名称、说明、分类下拉选择器、标签。
     - 题型添加条：单选、多选、填空、判断、匹配。
     - 题目列表与题数统计。
     - 单试卷导出 / 导入操作按钮。
6. **测试回退导航**:
   - 点击 `← 返回试卷列表`：确认侧边栏回到 Level 2 试卷列表。
   - 点击 `← 返回分类列表`：确认侧边栏回到 Level 1 分类列表。
7. **主观清晰度确认**:
   - 确认侧边栏在任意时刻均只呈现一个核心选择层级，大幅降低视觉负担与层级混乱感。

## 验证旅程 2: 分类管理、无障碍支持与创建

### 目标
验证侧边栏分类导航面板具备完备的键盘无障碍支持（无嵌套按钮非法标记）、显示准确的试卷计数、拦截系统保留名称，支持新建空分类并在刷新后稳定持久化。

### 步骤
1. 在 Level 1（分类层）测试键盘无障碍支持：
   - 使用键盘 `Tab` 键依次聚焦分类导航列表：
     - 确认每个分类项（所有试卷、各用户分类、未分类）均获得清晰的可视焦点轮廓。
     - 在聚焦时按 `Enter` 或 `Space` 键，可正常选中该分类并进入 Level 2。
     - 返回 Level 1，确认重命名（`✎`）与删除（`🗑`）按钮为独立可聚焦的 Tab 停靠点，可通过键盘单独触发。
2. 测试系统保留名称拦截：
   - 点击 **+ 新建分类**。
   - 输入 `"__ALL__"`、`"__NEW_CATEGORY__"` 或 `"__UNCATEGORIZED__"`：
     - 确认弹出提示 `"该分类名称为系统保留字，请使用其他名称"`。
     - 确认不会创建该保留字分类。
3. 点击 **+ 新建分类** 输入有效名称：
   - 在弹出的输入框中输入 `"数学"` 并确认。
   - 确认弹出提示 `"分类已创建"`。
   - 确认侧边栏自动进入该分类的 Level 2 界面，初始计数为 `0`。
   - 返回 Level 1 并刷新页面，确认空分类 `"数学"` 依然保留在列表中。
4. 新建第二个分类 `"语言"`：
   - 确认 `"语言"` 出现且计数为 `0`。

## 验证旅程 3: 试卷归类与分类搜索作用域

### 目标
验证试卷可以归入指定分类，在分类下新建试卷自动继承该分类，且搜索框自动限定于当前选中的分类。

### 步骤
1. 在 Level 1 选中 `"数学"` 进入 Level 2：
   - 确认试卷列表为空，显示 `"没有匹配的试卷"`。
   - 确认搜索框占位符提示在 “数学” 中搜索。
2. 点击 **新建** 试卷按钮：
   - 确认新建试卷的分类自动设为 `"数学"`。
   - 侧边栏自动进入 Level 3（题目层）。
   - 在试卷信息中输入标题 `"代数基础"`，标签输入 `"math, algebra"`。
   - 确认顶部卡片分类徽标显示 `"数学"`。
3. 点击 `← 返回试卷列表`：
   - 确认 `"代数基础"` 呈现在 `"数学"` 试卷列表中，计数变为 `1`。
4. 点击 `← 返回分类列表`：
   - 确认 `"数学"` 分类计数为 `1`，`"所有试卷"` 计数相应加 `1`。
5. 测试分类搜索作用域：
   - 进入 `"数学"`（Level 2），在搜索框输入 `"示例"`：
     - 确认无匹配结果。
   - 返回 Level 1 进入 `"所有试卷"`，保持搜索框中的 `"示例"`：
     - 确认示例试卷被检索出来。
   - 清空搜索框。

## 验证旅程 4: 试卷分类调整与行内新建分类

### 目标
验证可以通过试卷编辑区（Level 3）的分类选择器修改试卷分类、设为未分类，或直接行内新建并赋予新分类。

### 步骤
1. 打开一份示例试卷进入 Level 3。
2. 在试卷属性中找到 **分类** 下拉选择器：
   - 确认下拉列表包含 `"未分类"`、`"数学"`、`"语言"` 以及 `"+ 新建分类..."`。
3. 选择 `"语言"`：
   - 确认顶部试卷摘要卡片的分类徽标更新为 `"语言"`。
   - 返回 Level 1：确认 `"语言"` 分类的试卷计数变为 `1`。
4. 在分类下拉选择器中选择 `"+ 新建分类..."`：
   - 测试保留字拦截：输入 `"__NEW_CATEGORY__"` -> 确认弹出提示 `"该分类名称为系统保留字，请使用其他名称"`。
   - 在弹窗中输入 `"科学"` 并确认。
   - 确认弹出提示 `"分类已创建"`。
   - 确认当前试卷分类自动变为 `"科学"`，徽标更新为 `"科学"`。
5. 将分类调整为 `"未分类"`：
   - 确认试卷分类清空，徽标更新为 `"未分类"`。
   - 返回 Level 1：确认 `"未分类"` 计数加 `1`，`"科学"` 计数变为 `0`。

## 验证旅程 5: 分类重命名与防碰撞安全

### 目标
验证重命名分类更新分类注册表并自动无损传播给下属试卷，同时当重命名为已存在的其他分类名称或保留字时被安全拦截，防止静默合并分类。

### 步骤
1. 在 Level 1 确保 `"数学"` 分类下包含至少 1 份试卷。
2. 测试重命名撞名拦截（防静默合并）：
   - 点击 `"数学"` 分类项旁的重命名图标（`✎`）。
   - 输入 `"语言"`（该分类已存在）并确认：
     - 确认弹出提示 `"该分类名称已存在"`。
     - 确认重命名被安全拒绝：`"数学"` 与 `"语言"` 依然为两个独立分类，试卷归属保持不变（零静默合并）。
3. 测试重命名保留字拦截：
   - 点击 `"数学"` 分类项旁的重命名图标（`✎`）。
   - 输入 `"__ALL__"` 并确认 -> 确认提示 `"该分类名称为系统保留字，请使用其他名称"`。
4. 执行正常重命名：
   - 点击 `"数学"` 旁的重命名图标（`✎`）。
   - 在弹窗中将 `"数学"` 修改为 `"高等数学"` 并确认。
   - 确认弹出提示 `"分类已重命名"`。
   - 确认分类列表更新为 `"高等数学"`。
   - 进入该分类打开试卷，确认其分类字段与徽标均已自动更新为 `"高等数学"`。

## 验证旅程 6: 精细化分类删除弹窗与安全契约

### 目标
验证删除分类弹窗的视觉打磨与行为契约：标准弹窗头部、右上角关闭按钮、安全的“仅删除分类”选项卡、醒目的“删除分类及所有试卷”破坏性选项卡、次要取消按钮与二次确认。

### 步骤
1. **空分类删除**:
   - 在 Level 1 分类列表中点击空分类 `"科学"` 旁的删除图标（`🗑`）。
   - 确认弹出单次确认对话框：`"确定要删除空分类 “科学” 吗？"`。
   - 确认删除后，`"科学"` 从列表中移除，弹出提示 `"分类已删除"`。
2. **非空分类删除弹窗视觉与结构检查**:
   - 确保 `"高等数学"` 下包含至少 1 份试卷。
   - 点击 `"高等数学"` 旁的删除图标（`🗑`）。
   - 检查分类删除弹窗：
     - **头部**: 确认包含 `"删除分类"` 标题与右上角标准的关闭按钮（`✕` / `&times;`）。
     - **提示文案**: 确认清晰展示分类名称与下属试卷数量。
     - **安全选项卡**: 确认包含 `"仅删除分类"` 卡片，明确说明将保留试卷并设为未分类。
     - **破坏性选项卡**: 确认包含 `"删除分类及所有试卷"` 卡片，采用醒目的朱砂红提示样式与警示文案，标明永久删除试卷数量。
     - **取消按钮**: 确认底部提供次要样式的 `"取消"` 按钮。
     - **设计系统对齐**: 确认弹窗符合 Layered Paper Study Desk 的圆角、边框与纸张底色质感。
3. **非空分类删除 — 取消操作**:
   - 点击 **取消**（或右上角关闭按钮 `✕`）：
     - 确认无任何变更：分类与试卷均完好保留。
4. **非空分类删除 — 仅删除分类**:
   - 再次点击 `"高等数学"` 旁的删除图标（`🗑`）。
   - 点击 **仅删除分类** 按钮：
     - 确认 `"高等数学"` 从分类列表中删除。
     - 确认下属试卷依然保留在试卷库中，其分类变为 `"未分类"`。
     - 确认题目与试卷内容零丢失。
5. **非空分类删除 — 删除分类及所有试卷（破坏性删除）**:
   - 新建测试分类 `"临时分类"`，在其中新建 2 份试卷，并将其中一份设为当前打开的活动试卷。
   - 点击 `"临时分类"` 旁的删除图标（`🗑`）。
   - 点击 **删除分类及试卷** 按钮：
     - 确认弹出显式的破坏性二次确认弹窗：
       `"【危险操作】确定要删除分类 “临时分类” 及该分类下的全部 2 份试卷吗？此操作无法撤销！"`
     - 确认执行。
     - 确认 `"临时分类"` 及其下属 2 份试卷被彻底删除。
     - 确认活动试卷安全回退到剩余试卷（或默认试卷），`activePaperId` 始终合法有效。
