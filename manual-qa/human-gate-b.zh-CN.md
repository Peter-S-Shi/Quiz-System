# Human Gate B 人工验证指南 — 试卷库分类管理与集合式组织

**所属阶段**: 冻结前 V1 范围收敛 · Batch B（试卷库集合式分类组织）  
**评审状态**: 待人工验证 (PENDING HUMAN EVALUATION)  
**评估人**: 人工评审员 / 用户  

---

## 概述

本指南提供对“冻结前 V1 范围收敛 Batch B”新增的试卷库分类管理特性的逐项验收旅程：
1. **分类导航与筛选**: 包含所有试卷、用户创建分类（带试卷计数）、未分类（带计数）与“+ 新建分类”按钮的导航树。
2. **分类创建与空分类持久化**: 新建分类、空分类在刷新与备份中的持久化保留、分类作用域内的精确搜索。
3. **分类重命名**: 分类注册表更新并自动无损传播到该分类下的所有试卷。
4. **试卷分类调整与行内新建**: 通过试卷编辑侧边栏的分类感知选择器调整分类、移入未分类、或直接在选择器中新建分类。
5. **分类删除契约与安全保障**: 空分类单次确认删除；非空分类三向选择（取消 / 仅删除分类 / 删除分类及所有试卷）、二次破坏性确认与活动试卷回退安全。
6. **备份与恢复兼容性**: 完整备份 JSON 对分类注册表的保留，以及对历史无分类注册表备份文件的平滑兼容。

---

## 验证旅程 1: 分类导航与分类创建

### 目标
验证侧边栏分类导航面板显示准确的试卷计数，支持新建空分类并在刷新后稳定持久化。

### 步骤
1. 启动 Quiz Studio（执行 `start-local.bat` 或 `python scripts/dev-server.py`）。
2. 在顶部导航栏切换至 **编辑** 模式。
3. 检查侧边栏试卷库面板：
   - 确认在搜索框与操作按钮上方新增了 **分类** 导航区。
   - 确认默认高亮 **所有试卷**，并显示当前试卷总数。
   - 确认存在 **未分类**，并显示无分类试卷的数量。
   - 确认可见 **+ 新建分类** 按钮。
4. 点击 **+ 新建分类**：
   - 在弹出的输入框中输入 `"数学"` 并确认。
   - 确认分类列表中出现 `"数学"`，初始计数为 `0`。
   - 确认弹出提示 `"分类已创建"`。
   - 刷新浏览器页面，确认空分类 `"数学"` 依然保留在列表中。
5. 新建第二个分类 `"语言"`：
   - 确认 `"语言"` 出现且计数为 `0`。

## 验证旅程 2: 试卷归类与分类搜索作用域

### 目标
验证试卷可以归入指定分类，在分类下新建试卷自动继承该分类，且搜索框自动限定于当前选中的分类。

### 步骤
1. 在侧边栏分类列表中选中 `"数学"` 分类：
   - 确认试卷列表为空，显示 `"没有匹配的试卷"`。
   - 确认搜索框占位符更新为 `"在 “数学” 中搜索..."`。
2. 点击 **新建** 试卷按钮：
   - 确认新建的试卷分类自动设为 `"数学"`。
   - 在试卷信息中输入标题 `"代数基础"`，标签输入 `"math, algebra"`。
   - 确认 `"数学"` 分类计数更新为 `1`，`"所有试卷"` 计数相应加 `1`。
3. 选中 **所有试卷**：
   - 确认默认示例试卷与 `"代数基础"` 试卷均显示在列表中。
4. 测试分类搜索作用域：
   - 选中 `"数学"` 分类，在搜索框中输入 `"示例"`：
     - 确认无匹配结果（因为 `"代数基础"` 不包含 `"示例"`）。
   - 切换到 **所有试卷**，保持搜索框中的 `"示例"`：
     - 确认第一份示例试卷被检索出来。
   - 清空搜索框。

## 验证旅程 3: 试卷分类调整与行内新建分类

### 目标
验证可以通过试卷编辑区的分类选择器修改试卷分类、设为未分类，或直接行内新建并赋予新分类。

### 步骤
1. 在试卷列表中打开默认示例试卷。
2. 在左侧试卷属性栏中找到 **分类** 下拉选择器：
   - 确认下拉列表包含 `"未分类"`、`"数学"`、`"语言"` 以及 `"+ 新建分类..."`。
3. 选择 `"语言"`：
   - 确认试卷的分类更新为 `"语言"`。
   - 确认侧边栏 `"语言"` 分类的试卷计数变为 `1`。
4. 在分类下拉选择器中选择 `"+ 新建分类..."`：
   - 在弹窗中输入 `"科学"` 并确认。
   - 确认弹出提示 `"分类已创建"`。
   - 确认当前试卷分类自动变为 `"科学"`。
   - 确认侧边栏分类列表中出现 `"科学"` 且计数为 `1`。
5. 将分类调整为 `"未分类"`：
   - 确认试卷分类清空。
   - 确认侧边栏 `"未分类"` 计数加 `1`，`"科学"` 计数变为 `0`。

## 验证旅程 4: 分类重命名与自动传播

### 目标
验证重命名分类不仅更新分类注册表，还会将新名称无损自动传播给该分类下的所有试卷。

### 步骤
1. 将至少 2 份试卷归入 `"数学"` 分类。
2. 鼠标悬停在分类列表中的 `"数学"` 项：
   - 确认显示重命名图标（`✎`）与删除图标（`🗑`）。
3. 点击重命名图标（`✎`）：
   - 在弹窗中将 `"数学"` 修改为 `"高等数学"` 并确认。
4. 验证结果：
   - 确认弹出提示 `"分类已重命名"`。
   - 确认侧边栏分类列表更新为 `"高等数学"`，计数仍为 `2`。
   - 分别打开这两份试卷，确认它们的分类字段均已自动更新为 `"高等数学"`。
   - 确认两份试卷内的题目、标签、说明等内容完全未受任何破坏。

## 验证旅程 5: 安全删除分类契约

### 目标
验证删除分类的两个分支：空分类直接确认删除；非空分类提供三向选择（取消、仅删除分类保留试卷、删除分类及全部试卷），且删除活动试卷时有安全回退保障。

### 步骤
1. **空分类删除**:
   - 在分类列表中点击空分类 `"科学"` 旁的删除图标（`🗑`）。
   - 确认弹出单次确认对话框：`"确定要删除空分类 “科学” 吗？"`。
   - 确认删除后，`"科学"` 从列表中移除，弹出提示 `"分类已删除"`。
2. **非空分类删除 — 取消操作**:
   - 确保 `"高等数学"` 下有 2 份试卷。
   - 点击 `"高等数学"` 旁的删除图标（`🗑`）。
   - 确认弹出分类删除选择对话框，明确提示：
     `"分类 “高等数学” 下包含 2 份试卷。请选择删除方式："`
     并提供三个选项：
     - `仅删除分类（保留试卷为未分类）`
     - `删除分类及所有试卷 (2 份)`
     - `取消`
   - 点击 **取消**（或右上角关闭按钮 `✕`）：
     - 确认无任何变更：分类与 2 份试卷均完好保留。
3. **非空分类删除 — 仅删除分类**:
   - 再次点击 `"高等数学"` 旁的删除图标（`🗑`）。
   - 点击 **仅删除分类（保留试卷为未分类）**：
     - 确认 `"高等数学"` 从分类列表中删除。
     - 确认这 2 份试卷依然保留在试卷库中，其分类变为 `"未分类"`。
     - 确认题目与试卷内容零丢失。
4. **非空分类删除 — 删除分类及所有试卷（破坏性删除）**:
   - 新建测试分类 `"临时分类"`，在其中新建 2 份试卷，并将其中一份设为当前打开的活动试卷。
   - 点击 `"临时分类"` 旁的删除图标（`🗑`）。
   - 点击 **删除分类及所有试卷 (2 份)**：
     - 确认弹出显式的破坏性二次确认弹窗：
       `"【危险操作】确定要删除分类 “临时分类” 及该分类下的全部 2 份试卷吗？此操作无法撤销！"`
     - 确认执行。
     - 确认 `"临时分类"` 及其下属 2 份试卷被彻底删除。
     - 确认活动试卷安全回退到剩余试卷（或默认试卷），`activePaperId` 始终合法有效。
     - 确认被删除试卷的未完成练习进度被干净清除。

## 验证旅程 6: 备份与恢复兼容性

### 目标
验证用户创建的分类（包含空分类）在导出与导入全量备份 JSON 时完整保留，且历史旧备份能无损平滑升级恢复。

### 步骤
1. 创建分类 `"物理"`、`"化学"` 及空分类 `"生物"`，将试卷分别归入 `"物理"` 与 `"化学"`。
2. 在侧边栏底部点击 **备份**，导出全量备份 JSON。
3. 查看导出的 JSON 文件内容：
   - 确认 `library.categories` 包含 `["物理", "化学", "生物"]`。
4. 本地删除 `"生物"`，将 `"物理"` 重命名为 `"物理-旧"`。
5. 点击 **导入备份** 并选择第 2 步导出的 JSON 文件：
   - 确认弹出提示 `"已导入备份"`。
   - 确认 `"物理"`、`"化学"` 以及空分类 `"生物"` 完整恢复在分类列表中。
   - 确认所有试卷及其分类归属完全恢复。
6. 测试双语界面切换：
   - 在顶栏切换中英文语言。
   - 确认分类导航标题、按钮、占位符、对话框及 Toast 提示文本均完全中英双语本地化。
