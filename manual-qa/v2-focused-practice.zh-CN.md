# V2 Focused Practice — 手动验收清单

针对「Objective Answer Explanation + Focused Practice」里程碑，自动化套件**无法证明**的部分：真实 WebView2 中的真实系统输入法、真人阅读长文本界面，以及辅助技术。其余全部已自动化（`docs/V2_PRACTICE.zh-CN.md` 的“证据”一节）：DOM 自检用可信输入在真实 Chromium 引擎浏览器中驱动真实界面，打包应用烟测则在真实 WebView2 内运行固定的比较逻辑。

**以下条目全部 OPEN，没有任何一项 PASS，也没有任何一项被豁免。** 实际执行时把结果写进最右列；没有执行的条目保持“未执行”。

在已安装的应用（`quiz-studio.exe`，Windows 11，WebView2 Evergreen）上运行。Library → *Start a practice*。用 *Add a typing text* 添加一段 ≥ 3000 字符的文本（任意合成文字，夹杂几句中日韩文字），然后点 *Practice*。

| # | 检查 | 步骤 | 预期 | 结果 |
|---|---|---|---|---|
| M-T1a | 微软拼音（或微软日文/韩文输入法）组合输入 | 切到输入法，在候选窗打开时输入与原文一致的短语；分别用空格/回车和鼠标点候选来提交 | 候选窗打开时不会把任何内容标为已输入或出错；提交后恰好出现提交的文本并在原文中标为已输入；无重复、无丢字；光标仍在输入框 | 未执行 |
| M-T1b | 取消组合输入 | 开始组合，按 Esc | 组合被取消；**练习不会弹出退出对话框**；已提交文本不变 | 未执行 |
| M-T1c | 可能只发出 `input` 事件的第三方输入法 | 用搜狗/百度/Google 日语输入法等第三方输入法（或屏幕键盘/语音输入）输入文字 | 文字和其它输入一样被提交，不丢失；`N of M characters typed` 的计数一致 | 未执行 |
| M-T1d | 死键与 AltGr | 用死键布局（如 US-International）输入带音符字母 | 带音符字母被提交并按所输入内容比较 | 未执行 |
| M-T1e | 粘贴与拖放 | 粘贴文字（Ctrl+V、右键粘贴）以及把文字拖进输入框 | 被拒绝：输入框回退并出现简短提示；继续正常输入 | 未执行 |
| M-T2a | 长文本阅读与跟随 | 以正常速度把整段 ≥ 3000 字符的文本输完 | 原文自然换行；当前位置始终舒适可见；已完成的文字向上移出视野；无布局跳动、光标丢失或焦点丢失；用滚轮浏览时不会与你对抗，继续输入后恢复跟随 | 未执行 |
| M-T2b | 缩放 / DPI | 输入过程中把窗口调窄、调宽，并在不同缩放比例的显示器间移动 | 当前位置保持可见；已输入文本与焦点完好 | 未执行 |
| M-T2c | Test 意图 | 用 *Test* 开始同一段文本 | 输入过程中不显示任何对错信息；点 *Finish* 之后列出差异 | 未执行 |
| M-T2d | 中断与恢复 | 输入一半后关闭应用（或结束进程），重新打开，Library → *Unfinished* → *Resume* | 已输入文本与位置被恢复；完成后只记录一条结果 | 未执行 |
| M-T3a | 纯键盘（Objective） | 在两种反馈模式下，只用键盘（Tab、方向键、空格、回车、Esc）完成一份五题试卷 | 每个控件都能到达并操作；焦点始终可见；Esc 先询问再退出 | 未执行 |
| M-T3b | Narrator | 开启 Narrator，依次完成一道 Objective 题（即时反馈）、一句 Translation、一次 Typing | 题干、选项标签、进度、判分反馈和解析都会被朗读；原文可读；没有仅靠颜色传达的重要信息 | 未执行 |
| M-T3c | 高对比度与 200 % 缩放 | Windows 高对比度主题；显示缩放 200 % | 文字与控件仍清晰且不被裁切 | 未执行 |
| M-T4 | 打包 WebView 烟测 | `scripts/package-test.ps1`（CI 会运行） | `boot-status.json` 中 `webview.pinned_comparison` 与 `webview.engine_reported` 通过 | CI 自动化（见 `docs/V2_PRACTICE.zh-CN.md`） |

按设计不在本里程碑内：题目内图片/音频的显示、Today / Calendar / Library 最终视图、各种编辑界面。

> **最终 Human Gate Exit 证据所必需：** Product Owner 在最终打包候选版上执行 **M-T1a** 与 **M-T1c** 并在此记录真实结果（无法自动化；绝不记为自动化 PASS）。
