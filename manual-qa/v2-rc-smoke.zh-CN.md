# V2 Release Candidate —— 产品负责人冒烟指南（2.0.0-rc.1）

约 15–30 分钟，针对**确切的候选安装包**。这不是又一轮 Hardening：它只确认打包后的候选版身份正确，以及交付关键的流程在它上面可用。只用合成数据，绝不使用你真实的学习数据。

每项记录 **PASS / FAIL / NOT RUN**，并写明日期和所用安装包。**没有亲自执行就不是 PASS**；本指南不预先标记任何结果。缺少环境的项保持 NOT RUN 并写明原因。

## 准备（一次）

1. 从绿色的 CI-L3 run 下载候选安装包（run 37176744235，artifact `quiz-studio-2.0.0-rc.1-cec737b-installer`），把它的 SHA-256 与 `34FE8E4DD189DB6281104C9D0EDE7B6178E1EA10A39A2243AE948E43774F052F` 核对（`rc-evidence.json`，同样抄录在 `docs/V2_RELEASE_CANDIDATE.md`）。
2. 生成合成夹具：`powershell -File desktop\scripts\make-hardening-pack.ps1 -Out "$env:TEMP\qs-rc-pack" -BigBackupMiB 8 -DropFileGiB 1`（这里小一点的“大备份”就够；1 GiB 文件可跳过）。
3. 想要干净且无害的运行，使用带样例数据的文件夹：安装后在命令行里先设置 `$env:LOCALAPPDATA="$env:TEMP\qs-rc-pack\data-root"` 再启动应用；或者在测试用的 Windows 账户上让应用自己新建数据文件夹。

## 检查项

| # | 检查 | 步骤 | 预期 | 结果 |
|---|---|---|---|---|
| R1 | 安装包与身份 | 运行安装程序。查看安装包文件、开始菜单项、窗口/任务栏图标，以及设置 → System | 按当前用户安装，没有管理员提示；安装包、开始菜单、窗口/任务栏、Windows“已安装的应用”中都是 **Ink-tail Q** 图标；设置 → System 显示 `Quiz Studio 2.0.0-rc.1` | |
| R2 | 干净启动 | 从开始菜单启动 | 应用打开到“今日”，存储状态为 healthy，没有错误对话框 | |
| R3 | 带媒体的客观题流程 | 资料库 → *Figures and sounds*（样例）→ 练习。作答、完成、查看结果 | 图片显示、声音能播放，解析按所选反馈模式出现在正确位置，得分横幅和逐题卡片出现，该次作答出现在证据历史中 | |
| R4 | 翻译 / Teacher Review | 资料库 → 样例翻译文档 → 练习并完成；打开“批改”并保存一份批改 | 作答与批改在历史 / 批改中是分开的记录 | |
| R5 | 跟打流程 | 资料库 → 新建 → 跟打文本（粘贴一小段）→ 练习并打完 → 完成 | 结果显示*用时*；历史里有这次记录 | |
| R6 | 今日 / 日历的开始路径 | 今日 → 开始一条建议；然后日历 → 打开某天，开始或移动一次安排 | 练习记录了开始的理由；日历的改动按其身份显示 | |
| R7 | 备份与恢复 | 交换与备份 → *立即备份…* → 保存。再新增一份试卷。*选择备份…* → 确认 | 备份之后新增的试卷消失、原有数据恢复；恢复前的数据保留了快照 | |

| R9 | 升级保留数据（仅当你已装有 pre-RC 版本） | 应用中已有数据时，把 RC 覆盖安装上去 | 升级后数据仍在。没有更早版本则为 NOT RUN | |
| R10 | 卸载时的数据选择（可选；自 Hardening 以来候选版的打包方式没有改变这一行为） | 卸载两次：先不勾选删除数据，再勾选 | 不勾选保留数据；勾选则删除。可选 | |

## 如果失败

写下条目、你做了什么、看到了什么、所用安装包名。数据完整性、安全、迁移 / 升级、无障碍或已冻结工作流方面的失败属于发布阻断项，会被复现并修复；其它情况只记录并带入后续。任何修复都会改变候选版，需要新的确切候选证据。
