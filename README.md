# Quiz Studio

这是一个本地静态版 quiz 系统原型。直接打开 `index.html` 即可使用。

## 第一版功能

- 编辑试卷名称、说明和题目。
- 支持单选题、多选题、填空题、判断题、一对一匹配题。
- 单选题和多选题可设置正确/错误选项。
- 每次开始做题时，选择题选项会重新打乱。
- 匹配题右侧答案会在做题时重新打乱。
- 答对显示绿色对钩，答错显示红色叉号。
- 支持亮色和暗色背景切换。
- 试卷自动保存到浏览器本地存储。
- 支持导出/导入 JSON 试卷文件。

## 使用方式

1. 打开 `index.html`。
2. 在“编辑”页面添加或修改题目。
3. 切换到“做题”页面并点击“开始做题”。

后续可以继续扩展用户系统、题库管理、考试记录、后台数据库、AI 出题和主观题批改。
